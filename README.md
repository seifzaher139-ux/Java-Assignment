# Java Assignment

A small Java console program from my Java course. It is a menu-driven "Number Analyzer" with a few simple methods.

## What it does

- Prints the numbers from 10 down to 1
- Prints the numbers from 1 to 10 and says whether each one is odd or even
- Checks if a number is positive, negative, or zero
- Adds two numbers
- Shows a menu in the console so you can choose an option

## Concepts practiced

- Methods with parameters and return values
- Loops and if / else conditions
- Reading input with `Scanner`
- Javadoc comments

## How to run

1. Open the project in IntelliJ IDEA.
2. Run the `NumberAnalyzer` class (`src/javaAssignment/NumberAnalyzer.java`).
3. Pick an option from the menu.
